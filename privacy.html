Privacy Policy

Chainflip Quick Swap · Last updated: March 2026

What this extension does

Chainflip Quick Swap is a browser extension that fetches live swap quotes from Chainflip's public API and opens swap.chainflip.io with pre-filled values. It also displays live earn APYs, service status, and FLIP price data. It does not execute swaps directly and does not connect to any wallet.

Data we collect

None. This extension does not collect, transmit, or store any personal data on external servers. There are no analytics, no tracking, and no telemetry.

Data stored locally

The extension stores the following data in your browser's local storage and extension storage (never sent anywhere): swap preferences (selected assets, amounts, mode), saved wallet addresses in the address book, swap history (local log of quotes you opened), UI settings (network, boost preference), and 30-day service status history for the Status tab.

You can clear all stored data at any time by removing the extension or clearing your browser data.

Network requests

The extension makes requests to the following services. No personal data is included in any request.

Chainflip Swap API (chainflip-swap.chainflip.io) — to fetch swap quotes. Only the asset pair and amount are sent.

Chainflip GraphQL Services (cache-service.chainflip.io, lp-service.chainflip.io, reporting-service.chainflip.io) — to fetch live earn APYs, sparkline history, and service health checks.

Chainflip Swap App (swap.chainflip.io) — to check service availability and to open swaps.

CoinGecko API (api.coingecko.com) — to fetch USD prices and FLIP 30-day price chart data.

Permissions

storage — to save preferences and service status history locally.

alarms — to run periodic service health checks every 30 minutes in the background.

scripting — to pre-fill swap values on swap.chainflip.io when you open a swap.

activeTab — to interact with the swap.chainflip.io tab that opens.

These permissions are used only for the described functionality. The extension cannot read or modify any other websites.

Third parties

This extension is built by a community contributor and uses Chainflip's public APIs and CoinGecko's public API.
